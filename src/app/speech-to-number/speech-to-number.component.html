  1. Press Start and allow the microphone.
  2. Go to the website you want to use (keep this tab open in the background).
  3. Say (or type, if the keyboard is on) the yellow number next to what you want to click.
Good to know

Numbers stay the same while an element is on screen and update after scrolling or page changes. Only what is visible in the window is numbered. The extension adds an overlay to the page but does not change the page itself.
